# PetaByte — design brief (redesign, 2026-11)

**Who visits:** small-business owners in Baku (restaurants, pharmacies, services) checking whether PetaByte can build their site. In the first 5 seconds they need to see real work, what we build, and a way to write on WhatsApp.

**Concept:** a workshop index. The page reads like a well-kept list of finished jobs, with spec lines in monospace, big project numbers and real screenshots. No fake dashboards, no "premium" claims.

**Type:** Unbounded (display: wordmark, headings, numerals) + Onest (text). Both support Cyrillic and Azerbaijani letters. System monospace is used for spec lines.

**Color:**
- paper `#F3F1EC`, paper-2 `#E8E5DC`
- ink `#141414`, muted `#55524B`, line `#D3CFC4`
- accent vermilion `#E4572E`: buttons (with ink text, 5.6:1), numerals, underlines. Never used for small text on paper.
- contact band: ink background, paper text, accent `#FF6B3D`.

**Signature element:** large accent project numerals (01, 02, 03) with a monospace spec line above each title.

**Layout rhythm:**
1. The hero is asymmetric: text on the left, real screenshots (desktop and phone) on the right.
2. Work is an editorial list with full-width rows and big screenshots.
3. Services form a dense price-list table.
4. Contact is a dark band with large direct links and a 3-step process.

**Removed on purpose:** the purple gradients, glass effects, grid background, fake code/dashboard mock-up, "Premium design / Clean code" badges, fade-up reveal animations, floating panel, modal and hamburger menu (only 3 links).

**Still `[ЗАМЕНИТЬ]`:** service prices; the site domain (for canonical/OG absolute URLs).
