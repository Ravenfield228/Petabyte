# PetaByte — сайт-визитка веб-студии (Баку)

Сайт-портфолио: работы (Water Garden, Vicon Pharm, демо QR-меню), услуги, контакты. Языки: AZ / RU / EN.

- Без сборки: `index.html`, `styles.css`, `script.js`, `favicon.svg`, `assets/`.
- Тексты и переводы, проекты и цены — в `script.js` (объекты `T`, `PROJECTS`, `SERVICES`).
- Цены: в `SERVICES` поставить число (`price: 400`) вместо `null`, иначе показывается «по запросу».
- Дизайн-бриф: `DESIGN.md`.
- Исходная версия сохранена в теге `original`.

Локальный просмотр: любой статический сервер из корня, например `npx serve .`
